# Zig 0.16.0 style guide

Pinned to the style-guide section of the versioned Zig 0.16.0 language
reference. The guide describes itself as a point of reference rather than a
set of compiler-enforced rules. It covers redundant and fully qualified names,
underscore prefixes, whitespace, identifier and filename casing, and doc
comments.

Some naming and line-length recommendations differ from the stricter pinned
TigerStyle profile. The synthesis page records those seams rather than treating
the two sources as interchangeable.

Relevant pages: [[naming-comments-and-api-shape]], [[steering-zig-fmt]], and
[[zig-0.16-baseline]].
