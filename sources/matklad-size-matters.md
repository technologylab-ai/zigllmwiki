# matklad — Size Matters

Pinned to the `matklad.github.io` repository commit recorded above. The essay
separates physical review limits, such as fitting a function on one screen,
from architectural decomposition. Modules should keep related implementation
together while exposing a small interface; raw file length is not itself a
module boundary.
