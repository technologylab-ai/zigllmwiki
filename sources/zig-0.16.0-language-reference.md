# Zig 0.16.0 language reference

Pinned to the versioned language reference for Zig 0.16.0. It is the authority
for the language-level behavior of integer casts and overflow, auto/extern/
packed layout, backing integers, bit sizes, and byte reinterpretation.

Use the separately pinned 0.16.0 release notes for behavior that changed in
this release, and use standard-library source for helpers such as
`std.math.cast`, `std.math.add`, `std.mem.readInt`, and `std.mem.writeInt`.

Relevant pages: [[integer-widths-and-boundaries]], [[newtype-indexes]], and
[[invariants-and-assertions]].
