# Zig 0.16.0 release notes

Primary release document for the active version. The release is dated
2026-04-13. The I/O section identifies `std.Io.Threaded` as feature-complete and
the `main` default, while describing evented implementations as experimental,
unfinished, or proof-of-concept.

Use the installed 0.16.0 standard-library source for exact signatures and
implementation behavior.
